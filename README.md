# Netflix Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing a Netflix dataset for business analytics and reporting using Python and Pandas.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Darsh (3D Visualization)

## Project Workflow
1. Import the Netflix dataset using Pandas.
2. Identify and handle missing values.
3. Remove duplicate records and formatting inconsistencies.
4. Standardize Country, Rating, and Type columns.
5. Explore the dataset using visualizations.
6. Export the cleaned dataset as a CSV file.

## Visualizations
- Missing Values Analysis
- Movies vs TV Shows
- Top 10 Countries
- Rating Distribution
- Release Year Distribution
- 3D Scatter Plot using Darsh

## Project Files
- `main.ipynb` — Data cleaning and visualization notebook.
- `data/Dataset.csv` — Original dataset.
- `data/Cleaned_Netflix.csv` — Cleaned dataset.

## How to Run
1. Install the required Python libraries.
2. Open `main.ipynb` in Jupyter Notebook or VS Code.
3. Run the notebook cells in sequence.

## Project Objective
To improve data quality and prepare a structured dataset for further analysis and reporting.
